# Newton–Raphson Method Benchmark

**Category:** Floating-Point / Numerical Computation  
**Source:** https://rosettacode.org/wiki/Newton%27s_method  

## Description
The Newton–Raphson benchmark iteratively computes the square root of a
fixed value using a fixed iteration count. It stresses floating-point
arithmetic and convergence loops without external libraries or I/O.

## Input Configuration
- Value: 12345.6789 (fixed)
- Iterations: 1000 (fixed)
- Deterministic, no I/O

## Characteristics
- Single-threaded
- CPU-bound
- Floating-point heavy
- No external dependencies
