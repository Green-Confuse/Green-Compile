# Gaussian Elimination Benchmark

**Category:** Floating-Point / Numerical Computation  
**Source:** https://rosettacode.org/wiki/Gaussian_elimination  

## Description
The Gaussian elimination benchmark performs forward elimination on a fixed
augmented matrix. It stresses floating-point arithmetic, nested loops, and
memory access without external libraries or I/O.

## Input Configuration
- Matrix size: 128x128 with augmented column
- Deterministic initialization, no I/O

## Characteristics
- Single-threaded
- CPU-bound
- Floating-point heavy
- No external dependencies
