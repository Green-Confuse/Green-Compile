# Knight's Tour Benchmark

**Category:** Computational / Algorithmic  
**Source:** https://rosettacode.org/wiki/Knight%27s_tour  

## Description
The Knight's Tour benchmark searches for a full tour on an 8x8 chessboard
using backtracking with a degree-based move ordering. It stresses recursion,
branching, and constraint checks without external libraries or I/O.

## Input Configuration
- Board size: 8x8
- Start position: (0, 0)
- Deterministic, no I/O

## Characteristics
- Single-threaded
- CPU-bound
- Backtracking search
- No external dependencies
