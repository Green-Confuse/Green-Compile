# Sudoku Solver Benchmark

**Category:** Computational / Algorithmic  
**Source:** https://rosettacode.org/wiki/Sudoku  

## Description
The Sudoku solver benchmark uses recursive backtracking to fill a fixed
9x9 puzzle. It stresses branching, constraint checks, and recursion depth
without external libraries or I/O.

## Input Configuration
- Fixed 9x9 puzzle (standard example)
- Deterministic, no I/O

## Characteristics
- Single-threaded
- CPU-bound
- Backtracking search
- No external dependencies
