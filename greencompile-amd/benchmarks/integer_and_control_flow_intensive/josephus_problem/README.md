# Josephus Problem Benchmark

**Category:** Computational / Algorithmic  
**Source:** https://rosettacode.org/wiki/Josephus_problem  

## Description
The Josephus benchmark computes the survivor position for a fixed n and k
using an iterative recurrence. It stresses loop-heavy control flow and
modular arithmetic without external libraries or I/O.

## Input Configuration
- N = 100000 (fixed)
- K = 3 (fixed)
- Deterministic, no I/O

## Characteristics
- Single-threaded
- CPU-bound
- Integer arithmetic
- No external dependencies
